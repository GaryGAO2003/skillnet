# 风格特征词对照表

给 mj-prompt 用。用「特征描述」代替在世画家或摄影师的名字：效果更稳定，也避开版权和署名争议。英文用于 Midjourney，中文用于即梦。词条都是常用写法，不是官方词表，拿不准时先试一两个词再叠加。

## 五、光线、构图、镜头、情绪词

- 光线：golden hour（黄金时刻）、blue hour（蓝调时刻）、backlit / rim light（逆光 / 轮廓光）、soft diffused light（柔和漫射光）、neon glow（霓虹光晕）、volumetric light（体积光）、overcast soft light（阴天柔光）。
- 构图：close-up（特写）、medium shot（中景）、wide shot（远景）、low angle（低机位）、bird's-eye view（俯视）、centered symmetrical（居中对称）、rule of thirds（三分法）、shallow depth of field（浅景深）。
- 镜头：35mm（街拍纪实感）、50mm（接近人眼）、85mm（人像压缩感）、macro（微距）、fisheye（鱼眼）、tilt-shift（移轴）。
- 情绪：cozy（温馨）、serene（宁静）、dreamy（梦幻）、nostalgic（怀旧）、melancholic（忧郁）、whimsical（俏皮）、dramatic（戏剧性）。
- 常用排除项（放进 `--no`）：text、watermark、blurry、low quality、cropped、extra fingers。

## 六、写提示词的几个习惯

- 描述互相打架会让画面糊：「极简」和「细节极其丰富」不要同时出现。
- 具体物件胜过抽象形容：写「一盏暖黄的路灯」，少写「很有氛围」。
- 数量写明：「一只猫」「两个人」，否则模型会自己加。
- 一条提示词一种主风格，想混合就明确主次，例如「以水彩为主，加一点复古海报的版式」。
- 想要某位在世艺术家的感觉时，先问清楚想要的是色彩、笔触、构图还是氛围，再把它翻译成上面的特征词。
