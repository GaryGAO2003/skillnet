# 口播稿润色

把书面稿改成念得顺、听得懂的口播稿。保留原意，去掉书面腔，标好停顿和重音，估好时长。

## 什么时候用
- 稿子念起来拗口、卡壳，像在读公文。
- 要录口播、配音或直播话术，需要标好停顿和重音。
- 要把文案压进固定时长，例如 30 秒、60 秒。
- 不适合：必须逐字不改的法务声明、合同条款、药品说明。这类只能加停顿标记，不能改字。

## 先问清楚
信息够就直接做。只有缺下面两项、又无法推断时才问，最多 2 个问题：
1. 想要什么语气：亲切、专业还是搞笑？没说就按「亲切、像对朋友说话」。
2. 有没有时长或字数限制？没说就保持在原稿长度附近。

口号、品牌名、数字和专有名词一律原样保留。

## 怎么做
1. 先抽主旨和必须保留的信息：一句话主旨，加上不能改的数字、名称和事实。
2. 去书面语：把「该、其、此、之、予以、进行、旨在、因此、此外、综上所述」换成口语的「这个、它的、所以、还有、总之」，或者直接删掉。
3. 拆短句：一口气一句，大约不超过 15 个字；一句一个意思；先说结论再说原因；主语放前面。
4. 加节奏标记：`/` 是短停顿（约 0.3 秒），`//` 是长停顿（约 0.8 秒），换意思、转折、制造悬念前用长停顿；`「」` 包住重音词，每句最多 1 个，每 3–4 句才安排一个最强的重音。
5. 避开难念的地方：绕口（连续同声母或同韵的字）、同音易混、长数字、英文缩写。数字改成口语读法（30% 读「三成」或「百分之三十」），英文缩写第一次出现时解释。
6. 算时长：字数 ÷ 4.5 ≈ 秒（正常语速；较快用 5.5，较慢用 3.5），再加上停顿：每个 `/` 约 0.3 秒，每个 `//` 约 0.8 秒。
7. 不编造：原稿没有的数字、功效、对比一律不加。需要具体数据的地方用【补：…】占位，并在末尾提醒用户补真实数据。

## 输出格式
```text
口播稿（{n} 字，约 {x} 秒，含停顿）：
{句子 / 句子 // 句子，重音用「」}
标记说明：/ 短停顿　// 长停顿　「」重音
时长估算：{n} 字 ÷ 4.5 + 短停顿 {a} 个 × 0.3 + 长停顿 {b} 个 × 0.8 ≈ {x} 秒
改动说明：
- 删掉：{书面语或空话}
- 换成：{书面词 → 口语}
- 保留：{必须保留的信息}
需要你补充：{缺的数据或需要确认的信息；没有则写「无」}
```

## 质量标准 / 避坑
- 一定要出声念一遍。默读不算，卡住的地方就是要改的地方。
- 保留原意：结论、数据、肯定和否定的关系都不能变。「不一定」不能被改成「一定」。
- 不虚构用户评价、销量和对比数据。有疑问的数字，用占位并提醒。
- 重音别标多，全是重音等于没有重音。
- 商业口播里「最」「第一」「100% 有效」这类绝对化用语和功效承诺有违规风险，不替用户添加，原稿里有的要提醒。
- 停顿秒数和语速都是估算，实际因人而异，以本人念出来的时长为准。
- 儿化音、方言读法以本人习惯为准，不强行统一。

## 示例
**你说**：（语气亲切，30 秒内）本产品采用先进技术，能有效提升效率。它支持一键生成字幕，并自动匹配音效。用户无需具备专业技能即可快速上手。（补充：这是个剪辑工具，我自己用下来每天大概省一小时）

**口播稿**（45 字，约 14 秒，含停顿）：

说真的 / 这个剪辑工具 // 帮我每天省了「大概一小时」//
字幕 / 它能「一键」生成 / 音效也自动配好 //
不用学剪辑 / 打开就会用

**标记说明**：/ 短停顿　// 长停顿　「」重音
**时长估算**：45 字 ÷ 4.5 = 10 秒，加短停顿 4 个 × 0.3 秒、长停顿 3 个 × 0.8 秒，约 13.6 秒，取整 14 秒。离 30 秒还有余量，可以补一个使用场景或一句行动号召。

**改动说明**
- 删掉：「采用先进技术」。这是没有具体信息的空话；如果有具体的技术点，告诉我，我再放回去。
- 换成：「本产品」→「这个剪辑工具」；「有效提升效率」→「帮我每天省了大概一小时」（用的是你补充的实测）；「支持……并自动匹配」→「它能……也自动配好」；「用户无需具备专业技能即可快速上手」→「不用学剪辑，打开就会用」。
- 保留：一键生成字幕、自动匹配音效、上手门槛低这三个信息点。

**需要你补充**：「大概一小时」是否符合你的实际情况？如果要对外宣传，保留「我自己用下来」这样的个人限定，不要写成对所有人的承诺；有以前和现在的耗时对比的话，告诉我，可以加一句更有说服力的。
