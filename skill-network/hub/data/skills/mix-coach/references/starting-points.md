# 混音起步参数与检查清单

给 mix-coach 用。所有数值都是「先从这里试」的起点。不同的歌、不同的音色、不同的监听环境，合适的数值都不一样，最终以听感为准。

## 一、增益结构

- 每条轨道的峰值大致留在 -18 到 -12 dBFS，总线峰值在混音阶段留在约 -6 dBFS，给母带留余量。
- 先用推子和声像做静态平衡，再动 EQ 和压缩。顺序是：整理 → 静态平衡 → EQ → 压缩 → 空间 → 总线。
- EQ 先减后加：减的时候用窄一点的 Q 扫频找到最难听的点，减 2–3 dB；加的时候用宽一点的 Q，每次 1–2 dB。

## 二、乐器起步表

| 乐器 | EQ | 压缩 | 空间 / 声像 |
| --- | --- | --- | --- |
| 人声 | 高通 80–100 Hz；200–400 Hz 发闷就减 2–3 dB；3–5 kHz 加 1–2 dB 提清晰度；齿音在 6–8 kHz，用去齿音处理 | 3:1–4:1，启动 10–30 ms，释放 100–200 ms，压 3–6 dB | 居中；板式混响 1.0–1.8 秒，预延迟 20–40 ms；延迟用四分或八分音符，反馈调低 |
| 底鼓 | 高通 30 Hz；60–80 Hz 出厚度；300–400 Hz 去闷；3–5 kHz 出点击感 | 4:1，启动 20–30 ms，释放 60–100 ms，压 2–4 dB | 居中，基本不加混响 |
| 军鼓和边击 | 高通 100–150 Hz；200 Hz 出身体；5 kHz 左右出脆度 | 3:1–4:1，启动 10–20 ms，释放 80 ms，压 3–5 dB | 居中；短混响 0.4–1.0 秒 |
| 踩镲和打击乐 | 高通 300–500 Hz；刺耳就在 3–5 kHz 减 1–2 dB | 一般不压 | 偏左或偏右，各 15%–40% |
| 贝斯 | 高通 30–40 Hz；50–100 Hz 出厚度；250 Hz 浑浊就减；700 Hz–1 kHz 加一点，小音箱里才听得见 | 4:1，启动 20–30 ms，释放 80–150 ms，压 3–6 dB | 居中，不加混响；120 Hz 以下保持单声道 |
| 钢琴和键盘 | 高通 60–80 Hz；250–400 Hz 浑浊就减；高频按风格调 | 2:1–3:1，启动约 30 ms，释放自动，压 1–3 dB | 宽度 60%–100%；混响 1.2–2.0 秒 |
| 原声吉他 | 高通 80–100 Hz；200–300 Hz 浑浊就减；5–10 kHz 加一点空气感 | 2:1–3:1，压 2–4 dB | 双轨时左右各偏 50%–80% |
| 电吉他 | 高通 80–100 Hz；失真吉他在 2–4 kHz 容易盖住人声，可减 1–2 dB | 失真轨通常不再压 | 双轨左右拉开；混响和延迟适量 |
| 弦乐和 Pad | 高通 150–200 Hz；2–4 kHz 小幅减 1–2 dB 给人声让位 | 一般不压 | 宽度大；混响 2–3 秒 |
| 合成器主音 | 高通 100 Hz；按音色调，刺耳就在 2–5 kHz 减 | 2:1，轻压 | 居中或略宽；延迟增加空间 |

## 三、响度与导出

- 流媒体会对过响的歌做响度均衡，常见参考：Spotify 约 -14 LUFS，YouTube 约 -14 LUFS，Apple Music 约 -16 LUFS。各平台规则会调整，以平台最新说明为准。
- 目标：整曲综合响度（integrated LUFS）约 -14，真峰值（true peak）不超过 -1 dBTP。动态大的风格（lofi、民谣、古典）略低也完全可以。
- 响度不够时，先检查混音平衡和低频是否堆积，再考虑限制器，不要一上来就把限制器推到底。
- 交给母带工程师：24-bit WAV，不加限制器，总线峰值留 -6 dBFS 左右。自己发布：按平台要求导出，通常是 16-bit 或 24-bit WAV，采样率 44.1 kHz 或 48 kHz。

## 四、混音检查清单

1. 切到单声道：主旋律和低频还在吗？立体声素材有没有因为相位抵消变空？
2. 小设备：手机外放、小音箱、耳机、车载各听一遍，人声和低频是否清楚？
3. 参考曲 A/B：选一首风格接近的商业曲目，调到相同响度后对比低频量、人声位置、空间感。
4. 低频：底鼓和贝斯是否互相遮挡？200–300 Hz 是否堆积发糊？
5. 中频：人声是否被吉他、钢琴盖住？伴奏在 2–4 kHz 是否需要给人声让位？
6. 高频：镲片、齿音、合成器是否刺耳？是否过暗没有空气感？
7. 动态：压缩是否有明显的抽吸感？副歌是否比主歌有起伏？
8. 空间：混响和延迟是否盖住了节奏？每个段落的深度是否有层次？
9. 电平：总线是否留足余量？有没有爆音（clip）？
10. 导出：确认响度、真峰值、格式、采样率和文件名；导出后再听一遍成品文件。

## 五、常见问题先试什么

| 现象 | 先试 |
| --- | --- |
| 人声发闷 | 200–400 Hz 减 2–3 dB；3–5 kHz 加 1–2 dB；在伴奏的 2–4 kHz 小幅减 1–2 dB 给人声让位 |
| 低频糊 | 给底鼓和贝斯以外的轨道加高通；检查 200–300 Hz 堆积；底鼓和贝斯的主频错开 |
| 鼓和贝斯打架 | 用底鼓侧链压缩贝斯，压 2–4 dB；或错开节奏 |
| 声音太薄 | 检查是不是高通过头；100–200 Hz 加一点；适度加饱和增加谐波 |
| 声音太刺 | 2–5 kHz 减 1–2 dB；检查镲片和齿音；降低高频架 |
| 没有空间感 | 加短混响和延迟，注意预延迟；声像拉开 |
| 响度不够 | 先查平衡和低频，再用限制器；-14 LUFS 左右已经够用 |
