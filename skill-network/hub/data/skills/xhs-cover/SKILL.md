# 小红书封面标题

根据一篇笔记的内容，产出 10 个可直接使用的封面标题（分 5 组公式，每个不超过 20 字）和一套封面排版方案。标题负责让人想点，排版负责 3 秒内看懂。

## 什么时候用
- 要给小红书笔记（图文或视频）起标题、写封面大字、准备 A/B 备选。
- 已经有标题但觉得平淡，想看看换几种写法。
- 想检查标题或封面上有没有「最」「第一」「顶级」这类广告法极限词。
- 不适合：长文润色、正式的广告投放文案（需要另走合规审核）。

## 先问清楚
信息够就直接做，不要反问。只有缺下面两项、又无法从上下文推断时才问，最多 2 个问题：
1. 这篇笔记讲什么：主题，加上最有料的 1–3 个点（数字、结果、前后变化、价格）。
2. 给谁看：目标读者，以及是图文还是视频。

其余信息自己合理推断，并在输出第一行写明假设。

## 怎么做
1. 找钩子素材：从内容里挑最有张力的三类信息：具体数字、前后反差、读者痛点或身份。用户没给的数字不要编造，缺什么就写「无」。
2. 套公式出标题：从[标题公式库](references/title-formulas.md)挑最贴合的 5 种公式，每种写 2 个，共 10 个。
3. 卡字数：每个标题不超过 20 字（汉字、字母、数字、标点各算 1 个字，emoji 以发布页的字数提示为准），逐个数一遍并标出字数。关键词放在前 10 个字，因为信息流里标题常只露出前一两行。
4. 查极限词：对照公式库末尾的「极限词与风险词」，把绝对化说法换成可验证的个人表述。
5. 定封面：从下面 4 种版式里选 1 种，给出能照着做的指令。
6. 选 Top 3：说明理由，并建议准备 2–3 个封面或标题备选，分批测试后比较点击数据（平台没有官方 A/B 工具，数据有波动，仅作参考）。

封面版式（竖图 3:4，例如 1080×1440）：
- 大字报：纯色或虚化背景加 6–12 字主标题，字宽占画面 60% 以上。适合干货、清单。
- 前后对比：左右或上下等分，同机位同光线，各加「改造前」「改造后」小标。适合改造、护肤、减脂、装修。
- 拼图：4 宫格，或 1 大 + 3 小，主图占一半以上。适合合集、探店、好物。
- 人物 + 大字：人像占约一半，大字放在不遮脸的一侧。适合经验分享、知识类。

字体和颜色：
- 标题用粗黑体或圆体，选可商用字体（如思源黑体、阿里巴巴普惠体），避免细字和花体。
- 全图最多 3 种颜色：1 个底色或主色，1 个强调色（只给关键词），再加黑或白。文字与底色对比度至少 4.5:1，必要时加色块或描边。
- 四周留约 5% 边距；除大字报外，文字面积不超过画面的 1/3。缩到手机信息流的大小（约半屏宽）时仍能读清。

## 输出格式
```text
假设：{领域 / 读者 / 图文或视频}
钩子素材：数字 {…}｜反差 {…}｜痛点 {…}（没有就写「无」）

【A {公式名}】
1. {标题}（{N} 字）
2. {标题}（{N} 字）
【B {公式名}】3. …　4. …
【C {公式名}】5. …　6. …
【D {公式名}】7. …　8. …
【E {公式名}】9. …　10. …

推荐 Top 3：{序号}、{序号}、{序号}，理由：{一句话}
封面方案：
- 版式：{大字报 / 前后对比 / 拼图 / 人物+大字}
- 封面大字：{6–12 字，可由标题精简而来}
- 层级与配色：主标题 {位置、字号、颜色}；强调词 {颜色}；底色 {颜色}
- 拍摄 / 素材要求：{一句话}
极限词自检：{替换了什么，或「未发现」}
```

## 质量标准 / 避坑
- 每个标题都有「具体的东西」：数字、金额、人群、结果至少一项，不要只堆形容词。
- 标题必须被正文兑现。标题党换来的跳出和差评，比点击更伤账号。
- 不用极限词；慎用医疗功效词（治疗、根治）和站外引流词（微信、加V、私信领取），可能被限流或下架。
- 不编造数据，不虚构身份（如「专家」「医生」）。
- 只学公式，不照抄别人的爆款原句。
- 本 skill 不保证点击率：标题只是影响因素之一，内容、账号、发布时间同样重要，请用实际数据验证。
- 极限词清单是常见高风险词的汇总，不是法律意见，以最新《广告法》和平台公告为准。

## 示例
**你说**：分享我的租房改造（补充：月租 2000 元，改造花了 3000 元，没打孔，有前后对比图）

假设：图文笔记，读者是租房的年轻人，主打低成本、不伤房子，风格按 ins 风处理（按实际修改）。
钩子素材：数字 月租 2000、花费 3000｜反差 改造前后｜痛点 出租屋不能乱改

**A 数字清单型**
1. 月租2k的房子，被我改成了ins风（17 字）
2. 花3000块，把出租屋改成了家（15 字）

**B 反差对比型**
3. 同一个房间，改造前后像两个家（14 字）
4. 改造前后对比，我自己都不敢认（14 字）

**C 痛点提问型**
5. 不能打孔的出租屋，还能怎么改？（15 字）
6. 3000块改造出租屋，钱该花在哪？（17 字）

**D 结果承诺型**
7. 不打孔不动墙，出租屋也能变好看（15 字）
8. 预算3000，出租屋也能很有氛围感（17 字）

**E 身份场景型**
9. 租房党必看｜不打孔改造全记录（14 字）
10. 打工人的出租屋，终于像个家了（14 字）

**推荐 Top 3**：1、5、9。1 有金额和结果，关键词都在前 10 字；5 直击租房党最大的顾虑，容易引出评论；9 用人群标签精准筛选读者。

**封面方案**
- 版式：前后对比，左右等分，左「改造前」，右「改造后」，同机位、同时间段的光线。
- 封面大字：月租2k改成ins风（10 字）。
- 层级与配色：主标题放上方 1/3，白字加半透明黑条；「2k」放大约 1.3 倍，换亮黄 `#FFD60A` 作强调；左右下角各放一个小标。
- 拍摄要求：前后图保持同一角度，不要用滤镜夸大差异，避免被指误导。

**极限词自检**：10 个标题和封面大字中未发现「最」「第一」「顶级」等词，「必看」属于一般口语，可保留。
