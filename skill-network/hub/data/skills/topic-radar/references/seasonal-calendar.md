# 节点日历与常青题型

给 topic-radar 用。没有实时热点数据时，用这份日历找「未来 2–4 周内一定会发生的事」，再配合常青题型，就能稳定出选题。

使用前先确认今天的日期。下面的公历日期是固定的；农历节日每年的公历日期不同，要按当年日历核对，不要凭记忆写具体日期。

## 四、季节与行业节点（时间是大致范围，各地不同）

- 春：赏花踏青（3–4 月，樱花和油菜花看地区）、花粉过敏、换季护肤。
- 夏：高温、暑假、防晒、梅雨（江淮一带 6–7 月）、台风季（7–9 月）、荷花（7–8 月）。
- 秋：桂花（9–10 月）、银杏和红叶（10–11 月）、秋燥、换季穿搭、开学。
- 冬：初雪、暖气和取暖、火锅、滑雪、年终总结、年货。
- 考试季：中考和高考在 6 月，考研初试在 12 月下旬，国考和省考的报名与笔试时间每年公布，以当年公告为准。

## 五、节点怎么用

- 节前 7–10 天：攻略、清单、预算、避坑（「国庆去哪不挤」「双 11 别买这 5 样」）。
- 节中：现场感和情绪（vlog、氛围、小故事）。
- 节后 1–3 天：复盘、收纳、解腻、返程、节后综合征。节后内容常被忽略，竞争更小。
- 节点内容要提前准备，别等到当天才开拍，平台和观众的注意力都会前移。

## 六、常青题型

没有实时热点时，用「题型 × 你的领域」组合出选题。

| 题型 | 句式 | 例子（美食探店） |
| --- | --- | --- |
| 清单型 | {数字}个{东西} | 成都 5 家人均 30 的小馆子 |
| 对比型 | A 和 B 到底差在哪 | 同一道菜，两家店差在哪 |
| 避坑型 | 别再{错误做法} | 第一次来别急着排队 |
| 教程型 | 手把手教你{事} | 教你看懂菜单上的暗号 |
| 故事型 | 我{做了什么}，结果{变化} | 我连吃了一周苍蝇馆子 |
| 挑战型 | 一周 / 30 天{限制}挑战 | 一周 200 块吃遍一座城 |
| 盘点型 | 本地人才知道的{东西} | 本地人才知道的点单技巧 |
| 问答型 | 粉丝问得最多的{问题} | 评论区问得最多的三家店 |
