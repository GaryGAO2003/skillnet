# 灵感配色师

描述一种情绪或场景，得到 5 套差异明显、可直接取色的配色。每套都有 HEX 色值、角色分工、用法和对比度提醒。

## 什么时候用
- 给插画、海报、封面、PPT、UI、头像挑主题色，或者「说不清想要什么颜色，只有一种感觉」。
- 想要莫兰迪、复古、国风、霓虹等某种风格的现成色板。
- 想检查一组颜色上字好不好读。
- 不适合：要严格匹配品牌色或印刷专色（如 Pantone）的场合，这类以品牌手册或打样为准。

## 先问清楚
信息够就直接做。只有缺下面两项、又无法推断时才问，最多 2 个问题：
1. 用在哪：插画、海报、封面、UI 还是 PPT？（决定背景和文字怎么搭）
2. 有没有必须保留或必须避开的颜色？（品牌色、忌讳色）

没问到的，按「通用海报或封面」处理，并在开头写明假设。

## 怎么做
1. 把感觉翻译成色彩语言：冷暖（色相）、明暗（明度）、鲜灰（饱和度）。例：夏夜 = 冷色深底加一点暖光；汽水 = 高饱和青蓝加粉红；怀旧 = 降饱和并偏黄。
2. 先定 1 个主色，再找辅色：同色系（稳）、邻近色（和谐）、互补色（强对比，小面积用）。有彩色最多 3 个，其余用中性色。
3. 5 套要拉开差距：① 最贴题的直译 ② 更柔和、低饱和 ③ 反差、撞色 ④ 暗调或夜景版 ⑤ 意外但成立的一套（可用莫兰迪等风格）。
4. 每套固定 5 个角色：背景、主色、辅色、点缀、文字。色值写成 `#RRGGBB`，并取一个有画面感的色名。面积按背景与中性色 60%、主色加辅色 30%、点缀 10% 分配。
5. 查对比度：正文文字与背景至少 4.5:1，大字和图标至少 3:1。能运行代码时按 WCAG 公式算；不能运行时凭经验判断，并标注「估算」。
6. 写用法：谁做底、谁写字、点缀放在哪里；提醒屏幕与印刷有色差。

预设色板（含 6 套莫兰迪，对比度已算好）和对比度算法见 [references/palettes.md](references/palettes.md)，可以直接引用或在它的基础上改。

## 输出格式
```text
理解：{情绪或场景 → 冷暖 · 明暗 · 鲜灰}　用途假设：{…}

① {套名}（{一句话气质}）
背景 {色名} #HEX｜主色 {色名} #HEX｜辅色 {色名} #HEX｜点缀 {色名} #HEX｜文字 {色名} #HEX
用法：{谁做底、谁写字、点缀放哪里}
对比度：文字/背景 {x}:1，{正文可用 / 仅限大字}；{另一组需要提醒的对比度}
② …（共 5 套，格式相同）

推荐：{序号}，理由：{一句话}
提醒：色值是起点，请在目标屏幕上确认；要印刷请先打样。
```

## 质量标准 / 避坑
- 色值必须是合法的 6 位 HEX，不能用「淡蓝色」充当色值。
- 5 套要真有区别（色相、明暗、饱和度至少变两项），不要只是把同一套换个色相。
- 点缀色面积不超过 10%；有彩色超过 3 个就要降饱和度。
- 浅色主色放在浅底上通常不到 3:1，只能当色块，不要拿来写字。
- 深底配纯白字容易刺眼，可用略带色相的浅色。
- 别只靠红绿传达信息，要照顾色弱用户。
- 不要声称某种颜色「经科学证明能提升转化」；色彩的情绪联想因人和文化而异。
- 看不到成品，所有色值都只是推荐，实际画面里还要微调。

## 示例
**你说**：夏夜、汽水、有点怀旧（没说用途，按海报或封面处理）

理解：夏夜 = 冷色深底；汽水 = 高饱和青蓝加红粉点缀；怀旧 = 降一点饱和度、偏暖偏黄。

**① 汽水夏夜**（直译：深蓝夜空里冒汽水泡）
背景 夜空蓝 `#14213D`｜主色 汽水蓝 `#4FC3F7`｜辅色 月光黄 `#FFE08A`｜点缀 西瓜红 `#FF6B6B`｜文字 泡沫白 `#F4FBFE`
用法：夜空蓝铺底，汽水蓝做主体图形，月光黄用在标题和光点，西瓜红只给一个小亮点。
对比度：文字/背景 15.2:1，正文可用；点缀/背景 5.7:1，小字也够。

**② 褪色汽水**（更柔和，怀旧感最强）
背景 旧纸米 `#F2E8D5`｜主色 褪色蓝 `#5E9CB0`｜辅色 旧日黄 `#E2B65C`｜点缀 褪色红 `#D4604F`｜文字 炭棕 `#3A332B`
用法：米色做底，褪色蓝做大色块，旧日黄做标题底条，红色只给小标签；再加一点颗粒更像旧照片。
对比度：文字/背景 10.2:1，正文可用；主色/背景 2.5:1，只当色块，别拿来写字。

**③ 夜市霓虹**（反差：夏夜热闹的一面）
背景 深紫黑 `#0D0B1F`｜主色 霓虹青 `#00E5FF`｜辅色 霓虹粉 `#FF2E93`｜点缀 电光黄 `#FFE14D`｜文字 霓虹白 `#F5F5FF`
用法：青和粉对撞做灯牌效果，电光黄只点关键字，大面积用深底压住；文字用略带蓝紫的霓虹白，比纯白不刺眼。
对比度：文字/背景 17.8:1；霓虹粉/背景 5.5:1。荧光感颜色印刷会变灰，需要打样。

**④ 莫兰迪·夜蓝**（暗调：高级、安静）
背景 雾夜蓝 `#2E3B4E`｜主色 灰蓝 `#8DA4B5`｜辅色 燕麦 `#CBBBA4`｜点缀 灰玫红 `#C48B83`｜文字 暖白 `#F1ECE4`
用法：灰蓝与燕麦做主体，灰玫红只出现一两处；整体低饱和，适合文字较多的页面。
对比度：文字/背景 9.6:1，正文可用；主色/背景 4.3:1，大字和图标可用，小字请用文字色。

**⑤ 橘子汽水**（意外：暖亮的白天汽水）
背景 奶油白 `#FFF6E5`｜主色 橘子橙 `#FF9F45`｜辅色 薄荷青 `#2BBBAD`｜点缀 莓果红 `#E5383B`｜文字 深藏青 `#22304A`
用法：奶油白铺底，橙和薄荷做对比色块，深藏青写字；离开了「夜」，但保留了「汽水 + 夏天」。
对比度：文字/背景 12.3:1，正文可用；主色/背景 1.9:1，只当色块或插画。

**推荐**：先用 ①，想更怀旧选 ②，文字多的页面选 ④。
**提醒**：色值是起点，请在目标屏幕上确认；要印刷请先打样。
