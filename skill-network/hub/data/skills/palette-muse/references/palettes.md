# 配色速查库

给 palette-muse 用的预设色板。先按情绪找最接近的一套，再按用途微调（见文末「微调口诀」）。

- 每套 5 个角色：背景 / 主色 / 辅色 / 点缀 / 文字。建议面积比例：背景和中性色约 60%，主色加辅色约 30%，点缀约 10%。
- 对比度按 WCAG 公式计算，数值向下取一位小数（写 4.5 就是真的不低于 4.5）。正文小字需要 4.5:1 以上；大字、图标、按钮需要 3:1 以上；低于 3:1 的颜色只做装饰。
- 色值是起点，不是标准答案：不同屏幕、不同印刷工艺显示会有偏差，成稿前请在目标设备上看一遍。

## 微调口诀

- 想更柔和：饱和度降 10%–20%，明度加 5%–10%。
- 想更怀旧：整体色相往黄、棕偏一点（约 10°–20°），饱和度降 15% 左右，再加一点颗粒。
- 想更高级：有彩色最多留 2 个，其余用灰、米、深色等中性色，点缀色面积不超过 10%。
- 想更像夜晚：背景用带色相的深色（如 `#14213D`、`#0D0B1F`），不要用纯黑 `#000000` 配纯白，容易刺眼。
- 要印刷：荧光感的颜色（如霓虹青 `#00E5FF`）超出常见印刷色域，印出来会变灰变暗，务必打样确认。
- 要照顾色弱用户：不要只靠红和绿区分信息，同时加形状、文字或明暗差。

## 配色关系一页纸

- 同色系（同一色相的深浅）：稳、安全、好看，适合新手做底。
- 邻近色（色相环上相隔约 30°）：和谐、柔和。
- 互补色（相隔 180°，如蓝和橙）：对比强，小面积做点缀才好看。
- 三角或分裂互补：更活泼，要靠明度差和面积主次压住，否则会乱。
- 一套配色里最多 3 个有彩色，再加中性色；颜色越多，越需要降低饱和度。

## 对比度怎么算

```text
每个通道：c = 值 / 255；c ≤ 0.04045 时取 c / 12.92，否则取 ((c + 0.055) / 1.055) 的 2.4 次方
相对亮度 L = 0.2126 × R + 0.7152 × G + 0.0722 × B
对比度 = (较亮的 L + 0.05) / (较暗的 L + 0.05)
```
