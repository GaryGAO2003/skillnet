# 人像修图场景预设

给 portrait-retouch 用。每个预设都是起点：数值写成「推荐值（范围）」，Lightroom 的滑块名称为准，醒图找相近的滑块即可（没有的跳过）。所有数值都要先把曝光和白平衡调对，再套用。

## 使用约定

- 色温和色调：JPG 或手机直出图的色温滑块是相对值（-100 到 +100），往负偏冷偏蓝，往正偏暖偏黄；色调往负偏绿，往正偏洋红。RAW 的色温是开尔文数值，数值调高画面会更暖，思路相同。
- HSL 的色相滑块方向：橙色往左偏红、往右偏黄；黄色往左偏橙、往右偏绿；绿色往左偏黄、往右偏青。
- 面板位置：Lightroom 电脑版在「基本」「HSL」「色彩分级」「细节」「效果」；手机版在「光线」「颜色」「效果」「细节」。
- 看直方图：日系通透的山峰偏右但不贴死右边；电影暗调偏左但不贴死左边；胶片感的左端会离开边缘（抬起的黑位）。

## 一、胶片感（手机拍出胶片感）

目标：略褪色的黑位、偏暖的高光、偏冷的暗部、柔和的对比、颗粒。

| 参数 | 推荐值（范围） | 原因 |
| --- | --- | --- |
| 曝光 | 0（-0.2 ~ +0.3） | 胶片感不靠提亮 |
| 对比度 | +10（+5 ~ +20） | 保留一点力度，避免发灰 |
| 高光 | -15（-25 ~ -5） | 柔和亮部 |
| 阴影 | +10（0 ~ +20） | 暗部留细节 |
| 黑色色阶 | +15（+8 ~ +25） | 抬起黑位，是胶片感的核心；也可以在曲线里把左下角的点往上拉 8–15 |
| 色温 | +10（+5 ~ +18） | 整体偏暖 |
| 色调 | +4（0 ~ +8） | 一点洋红，皮肤更暖 |
| 饱和度 | -5（-12 ~ 0） | 胶片的颜色是「厚」而不是「艳」 |
| HSL 绿色 | 色相 -10，饱和 -20 | 绿色偏黄绿且不抢眼 |
| HSL 蓝色 | 饱和 -15 | 压低天空的浓度 |
| 色彩分级 | 阴影 色相 205 饱和 10；高光 色相 45 饱和 10 | 暗部偏冷、亮部偏暖 |
| 颗粒 | 数量 30，大小 25，粗糙度 50 | 颗粒度别太大，手机屏幕上会显脏 |
| 暗角 | -15（-25 ~ -5） | 把视线收向中间 |

醒图参考：褪色 +15、颗粒 +15、色温 +10、对比度 +8、高光 -10。

## 二、奶油肤质（室内暖光）

目标：肤色白皙细腻，暖但不黄。

| 参数 | 推荐值（范围） | 原因 |
| --- | --- | --- |
| 曝光 | +0.3（+0.1 ~ +0.6） | 提亮脸部 |
| 对比度 | -8（-15 ~ 0） | 光线更柔 |
| 高光 | -20（-35 ~ -10） | 避免额头和鼻梁反光过曝 |
| 阴影 | +15（+5 ~ +30） | 暗部透气 |
| 色温 | -8（-15 ~ -3） | 室内灯光偏黄，先往冷拉一点，保留一点暖才有「奶油感」 |
| 色调 | +5（0 ~ +10） | 洋红让皮肤粉嫩 |
| HSL 橙色 | 饱和 -8，明亮 +10 | 肤色白而不灰 |
| HSL 黄色 | 饱和 -20（-30 ~ -10） | 退掉暖光带来的黄 |
| HSL 红色 | 饱和 -5 | 脸颊和嘴唇别太艳 |
| 纹理 / 清晰度 | -8 / -5 | 皮肤柔和，保留五官轮廓 |

## 三、电影暗调

目标：低曝光、较高对比、青橙分离、暗部有情绪。

| 参数 | 推荐值（范围） | 原因 |
| --- | --- | --- |
| 曝光 | -0.4（-0.8 ~ -0.2） | 整体压暗，营造情绪 |
| 对比度 | +15（+8 ~ +25） | 增加戏剧性 |
| 高光 | -25（-40 ~ -10） | 防止亮部爆掉 |
| 黑色色阶 | -10（-20 ~ 0） | 暗部更沉 |
| 色温 | -5（-12 ~ 0） | 整体略偏冷 |
| 饱和度 | -10（-20 ~ -5） | 低饱和更像电影 |
| HSL 橙色 | 饱和 -5，明亮 +5 | 保住肤色，让脸从暗背景里浮出来 |
| 色彩分级 | 阴影 色相 210 饱和 20；高光 色相 40 饱和 12 | 暗部青蓝、亮部橙黄的青橙分离 |
| 暗角 | -15（-25 ~ -5） | 聚焦脸部 |
| 局部提亮 | 脸部蒙版 曝光 +0.3 ~ +0.6 | 整体压暗后，脸不能跟着变脏 |

## 四、逆光人像

目标：保住天空层次，同时让脸不欠曝。

| 参数 | 推荐值（范围） | 原因 |
| --- | --- | --- |
| 曝光 | +0.5（+0.2 ~ +1.0） | 逆光时脸通常欠曝 |
| 高光 | -50（-70 ~ -30） | 把天空和光晕拉回来 |
| 阴影 | +40（+25 ~ +60） | 提亮脸部 |
| 白色色阶 | -10（-25 ~ 0） | 防止亮处死白 |
| 去朦胧 | +8（0 ~ +15） | 去掉逆光的灰雾；想要梦幻光晕就不加 |
| 色温 | +5（0 ~ +10） | 金色日落感 |
| 降噪 | 明亮度 15–25 | 大幅提阴影会带出噪点 |
| 局部提亮 | 脸部蒙版 曝光 +0.3 ~ +0.6 | 比整体提亮更干净 |

## 五、夜景人像

目标：保住夜晚的黑，压住灯光爆点，让脸干净。

| 参数 | 推荐值（范围） | 原因 |
| --- | --- | --- |
| 曝光 | +0.3（0 ~ +0.8） | 脸为准，不要把夜晚提成白天 |
| 高光 | -40（-60 ~ -20） | 压住灯光的爆点 |
| 阴影 | +25（+10 ~ +45） | 暗部有细节 |
| 黑色色阶 | -5（-15 ~ 0） | 保持夜晚的黑 |
| 白平衡 | 用吸管点脸附近的中性点，再微调 | 混合光源下以肤色为准 |
| 降噪 | 明亮度 25（15 ~ 40），颜色 25 | 高 ISO 噪点多，降多了会糊，边看边调 |
| 饱和度 | -5 | 霓虹色容易溢出 |
| HSL 橙色 | 明亮 +5 | 脸更干净 |

## 六、现象 → 先调哪里

| 现象 | 先调 |
| --- | --- |
| 脸太暗 | 阴影 +，曝光 +0.2，橙色明亮 +；必要时用蒙版只提亮脸 |
| 整体发灰 | 白色色阶 +5、去朦胧 +3，对比度回调 |
| 肤色发黄 | 橙色色相往红偏 -3 ~ -5；黄色饱和 -5 ~ -15；色温往冷 -3 |
| 肤色发红 | 橙色和红色饱和 -5 ~ -10；橙色色相往黄偏 +2 ~ +4 |
| 肤色发青或发绿 | 色调往洋红 +3 ~ +6；色温往暖 +3 |
| 天空死白 | 高光降到 -30 或更低；白色色阶 -10 |
| 看起来很假、像塑料 | 纹理和清晰度回到 -5 以内；所有幅度整体减半再逐个加回 |
| 颜色太艳 | 先降饱和度，再单独降偏艳的颜色，不要只靠自然饱和度 |
| 噪点明显 | 降噪明亮度 15–25；别同时大幅提阴影 |

| Lightroom | 醒图里常见的对应滑块 |

| 色温、色调 | 色温、色调 |
| 饱和度 | 饱和度 |
| 纹理、清晰度 | 结构 |
| 锐化 | 锐化 |
| HSL | HSL（部分版本叫「色彩」） |
| 黑色色阶（抬黑位）、曲线 | 褪色、曲线 |
