# 人像修图参数

描述照片和想要的感觉，得到 Lightroom 和醒图的具体参数。每个滑块都有数值、调整范围和原因，数值是起点，不是标准答案。

## 什么时候用
- 拍完的人像偏灰、偏暗、偏黄或不够通透，想知道每个滑块该调多少。
- 想复刻一种感觉（日系通透、胶片、奶油肤色、电影暗调），需要一套能照做的参数。
- 想把 Lightroom 的思路换算到手机上的醒图。
- 不适合：精修（液化、换背景、大面积磨皮）请用专业工具；我看不到照片时不能保证效果。

## 先问清楚
信息够就直接做。只有缺下面两项、又无法推断时才问，最多 2 个问题：
1. 照片是在什么光线下拍的（阴天户外、室内暖光、逆光、夜景），最大的问题是什么（偏暗、偏灰、偏黄、脸太暗）？
2. 想要什么感觉（日系通透、胶片、奶油肤色、电影暗调……）？

软件没说就 Lightroom 和醒图都给；RAW 还是手机直出的 JPG 没说就按 JPG 处理（色温用相对值）。能看到图片就按图判断，看不到就按描述，并在回答里说明。

## 怎么做
1. 先修底子再上风格。顺序：曝光与白平衡 → 明暗（高光、阴影、白色、黑色）→ 对比与质感 → 色彩（HSL）→ 色彩分级 → 细节 → 肤色复核。
2. 肤色优先。人像的肤色主要落在橙色（含部分红和黄）里，调橙色的饱和度和明亮度时幅度要小，一般不超过 ±15。
3. 每个参数写「数值 + 范围 + 原因」，例如「曝光 +0.3（+0.2 ~ +0.6）：阴天偏暗，提到脸部落在直方图中间偏右」。
4. 数值是起点：同一组数字在不同的相机、手机和光线下效果不同。先把曝光和白平衡调对，再在建议范围内微调，每次只动 1–2 个滑块。
5. 醒图的滑块名称随版本略有差异，没有的滑块就跳过或用相近的代替。数值可以先照搬 Lightroom 的，再按观感上下调 5 左右。两款软件的算法不同，同一个数字的效果不会完全一样。
6. 最后做肤色检查（见下）。
7. 其他场景的预设（胶片感、奶油肤质、电影暗调、逆光、夜景人像）和「现象 → 先调哪里」对照表见 [references/presets.md](references/presets.md)。

## 质量标准 / 避坑
- 肤色检查：放大到 100% 看脸颊和额头，有没有发青、发绿、死白或橙红。肤色不应离开原本的色相太远。关掉手机的夜间模式和护眼模式再判断。
- 降对比、提阴影、降饱和叠在一起容易发灰，用白色色阶、去朦胧或曲线补一点层次。
- 不要过度磨皮：纹理和清晰度别低于 -10，皮肤的质感要保留，否则像塑料。
- 不同屏幕色温和亮度不同，成片在两三台设备上看一眼。
- 同一组照片用同一套参数，再按每张的曝光微调，整组才统一。
- 用于商业宣传的人像（护肤、医美、减脂等）不要用修图夸大效果，可能构成虚假宣传。
- 不保证一键出片：参数只是起点，审美判断仍然在你。

## 示例
**你说**：阴天户外人像，想要日系通透（手机直出 JPG，用 Lightroom 手机版和醒图）

**判断**：阴天光线平、偏暗偏灰，目标是高明度、低对比、低饱和、肤色干净。依据：只看描述，没有看到图片。

| 参数 | Lightroom | 范围 | 醒图对应 | 原因 |
| --- | --- | --- | --- | --- |
| 曝光 | +0.3 | +0.2 ~ +0.6 | 光感 +8（+5 ~ +15） | 阴天偏暗，提到脸部落在直方图中间偏右 |
| 对比度 | -12 | -20 ~ -5 | 对比度 -12 | 柔化光线，肤色更干净；太低会发灰 |
| 高光 | -30 | -45 ~ -20 | 高光 -30 | 阴天天空容易发白，拉回云层层次 |
| 阴影 | +20 | +10 ~ +35 | 阴影 +20 | 提亮脸部暗部，去掉沉闷感 |
| 白色色阶 | +10 | 0 ~ +20 | 亮度 +3（无直接对应） | 补回降对比后的干净亮部 |
| 黑色色阶 | +3 | 0 ~ +8 | 褪色 +3 | 轻微提起黑位带出空气感，过头会发雾 |
| 色温 | -6 | -10 ~ -3 | 色温 -6 | 整体往冷一点，出清爽感；画面已经偏蓝就不要再降；先用吸管点中性灰校准白平衡 |
| 色调 | +4 | 0 ~ +8 | 色调 +4（方向看滑块颜色） | 往洋红偏一点，肤色更粉嫩，也能抵消绿植的反光 |
| 去朦胧 | +5 | 0 ~ +10 | 无对应 | 去掉灰雾，增加通透感；超过 +10 会变暗变艳 |
| 纹理 / 清晰度 | -5 / -5 | -10 ~ 0 | 结构 -5 | 皮肤更柔和，眼睛和头发可局部加回 |
| 饱和度 / 自然饱和度 | -8 / +5 | -15 ~ -5 / 0 ~ +10 | 饱和度 -8 | 整体更干净，用自然饱和度保护肤色 |
| HSL 橙色 | 饱和 -10，明亮 +8 | 饱和 -15 ~ -5；明亮 +5 ~ +15 | HSL 橙色 同值 | 肤色在橙色里，降饱和加明亮就是白皙通透 |
| HSL 黄色 | 饱和 -15 | -25 ~ -10 | HSL 黄色 同值 | 压掉皮肤偏黄和杂黄 |
| HSL 绿色 | 色相 -10，饱和 -15 | 色相 -20 ~ -5 | HSL 绿色 同值 | 植物偏黄绿更清新，不抢人像 |
| 色彩分级 | 阴影 色相 210 饱和 8；高光 色相 45 饱和 4 | 饱和不超过 12 | 无则跳过 | 暗部偏冷、亮部偏暖，经典日系冷暖对比 |
| 锐化 | 30 | 20 ~ 45 | 锐化 +20 | 手机图适度锐化，不要把皮肤锐化出颗粒 |
| 颗粒 / 暗角 | 0 / 0 | — | 颗粒 0 | 通透风不需要，胶片感才加 |

**调整顺序**：1 曝光、色温校准 → 2 高光、阴影、对比 → 3 色调、饱和度 → 4 HSL 的橙、黄、绿 → 5 色彩分级 → 6 纹理、锐化。
**肤色检查**：脸颊有没有发青（色温退回 2–3 格）；有没有死白（橙色明亮降到 +5 以内）；有没有发灰（橙色饱和降多了会灰，别超过 -15）。
**不对劲时**：
- 整体发灰：白色色阶 +5、去朦胧 +3，或对比度回调到 -5。
- 肤色发黄：橙色色相往红偏 -3 ~ -5，黄色饱和再降 -5。
- 看起来很假：把所有参数的幅度整体减半，再逐个加回去。
