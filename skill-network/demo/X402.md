# x402 agent payments (REAL USDC on Base Sepolia)

The agent-invoke path (`POST /api/agents/:id/invoke`) is gated by a genuine **x402** HTTP-402
payment flow settled in **USDC on Base Sepolia** (chainId `84532`). No CDP keys, no gas: the
public **facilitator** submits the USDC transfer on-chain and sponsors gas.

## The two-leg money model

SkillNet moves money on two independent legs — do not confuse them:

| Leg | Surface | Asset | Direction | Where |
|-----|---------|-------|-----------|-------|
| **Ingress** (this doc) | agent invoke (`/api/agents/:id/invoke`) | **USDC** (6 dec) | buyer → `X402_RECEIVING_ADDRESS` | x402 protocol v2 + facilitator |
| **Egress** | skill-call royalties (`/api/call/:id`) | **ETH** (wei) | vault → creators | voucher / SettlementVault — see `GATEWAY.md` |

The x402 leg is real USDC in. The creator-distribution leg (voucher vault, ETH-wei) is a
**different surface** and is unchanged. Bridging x402 USDC revenue into a USDC-denominated
creator vault is **roadmap**: today the two legs are accounted separately, and per-agent USDC
earnings are tracked internally in the agent registry (`GET /api/agents/balances`,
`currency: "USDC"`), not yet swept on-chain to creators.

## The flow

```
POST /api/agents/:id/invoke                 (priced agent, no X-PAYMENT header)
  → 402  { x402Version:2, resource, accepts:[ { scheme:"exact",
           network:"eip155:84532", asset:<USDC>, amount:<micro-USDC>,
           payTo:<receiving addr>, maxTimeoutSeconds, extra:{name:"USDC",version:"2"} } ] }

buyer signs EIP-3009 transferWithAuthorization over accepts[0]
  → base64(PaymentPayload) in the  X-PAYMENT  header, retry the same POST

server → facilitator /verify → /settle  (facilitator submits USDC on-chain, pays gas)
  → 200 { success, invocation, payment:{ txHash, amountMicro, currency:"USDC", network, payer } }
       + X-PAYMENT-RESPONSE header (base64 settlement result)
```

Free agents (`feePerTask` 0, e.g. the seeded Qwen Agent) skip the gate entirely. A facilitator
or network failure returns **402 with a retryable error** — it never crashes the request.

### Pricing convention

An agent's numeric `feePerTask` is treated as a **USD-dollar** amount; USDC has 6 decimals, so
`feePerTask` micro-USDC `= round(feePerTask × 1_000_000)`:

| `feePerTask` | charged |
|--------------|---------|
| `0`     | free (no 402) |
| `0.001` | `1000` micro-USDC ($0.001) |
| `1`     | `1000000` micro-USDC ($1) |

## Environment

All have working defaults — **with zero env set the demo boots REAL** (x402.org facilitator,
default receiving address) and still boots fine offline (the facilitator client is built lazily
on first settlement; a failure falls back to a retryable 402, never a boot crash).

| Var | Default | Purpose |
|-----|---------|---------|
| `X402_MODE` | `real` | `real` = USDC on Base Sepolia; `sim` = legacy UUID-receipt flow (offline dev) |
| `X402_FACILITATOR_URL` | `https://x402.org/facilitator` | free, keyless, gas-sponsoring, base-sepolia only |
| `X402_NETWORK` | `eip155:84532` | CAIP-2 network id |
| `X402_USDC_ADDRESS` | `0x036CbD53842c5426634e7929541eC2318f3dCF7e` | official Circle USDC (EIP-3009) |
| `X402_RECEIVING_ADDRESS` | `0x7a549A1687f374715C74615748509aF976a3f32E` | where buyers' USDC is sent (`payTo`) |
| `DEMO_PAYER_SEED` | fixed dev constant | seed for the demo buyer wallet (server + E2E must match) |

`X402_MODE=sim` preserves the demo's original behaviour verbatim: `/api/agents/:id/pay` mints a
UUID receipt and `/invoke` consumes it (ETH-denominated). In `real` mode `/pay` returns **410 Gone**
pointing at the x402 flow.

## Buyer wallet & the Circle faucet

The E2E buyer wallet is derived deterministically (DEMO-MODE CUSTODY, same pattern as
`gateway.mjs`): `keccak256(DEMO_PAYER_SEED ‖ "x402-buyer")`. It needs **Base Sepolia USDC** —
gas is sponsored by the facilitator, so it needs no ETH.

1. Run the buyer script once to print the wallet address (below).
2. Fund it at the Circle faucet: **https://faucet.circle.com** → network **Base Sepolia**.
3. Re-run the script.

## End-to-end buyer script (manual — NOT run by tests, never commit output)

`scripts/e2e-x402.mjs` derives the buyer wallet, checks its USDC balance (prints the faucet URL +
address and exits 0 if empty), registers a priced agent on the local server, drives the full
402 → sign EIP-3009 → settle round-trip, and prints the settlement tx + Basescan link + the result.

```bash
cd skill-network/demo
node server.js                 # REAL mode by default (a second shell)
node scripts/e2e-x402.mjs      # honor PORT env for a custom port
```

Never prints private keys; amounts are integer micro-USDC / BigInt only.

## Tests

`test/x402.test.mjs` (node:test, **no network**): in-process unit tests inject a stubbed
facilitator into `X402Gateway` (mirrors `gateway.test.mjs`) covering the 402 challenge shape, the
paid flow (tx recorded + micro-USDC credited), facilitator/verify/settle failure modes, and sim
mode; plus spawned-server HTTP checks for the free-agent bypass, the 402 challenge, and the
retired `/pay` (410).
